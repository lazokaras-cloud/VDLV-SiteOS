The guidance is a deterministic rules engine, not a language model: dates and money are computed, never generated. Speech capture uses the browser recogniser where the page is allowed a microphone and a scripted stand-in where it is not. The reading of site photographs is illustrative. The project data is shaped to be plausible for a job of this size and is not taken from a real contract.
